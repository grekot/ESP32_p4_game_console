# Lekcja NN: Nazwa

> Wzór README lekcji. Kopiuj do `src/games/lekcje/NN_nazwa/README.md`, wypełnij sekcje, usuń ten cytat.
> Język dla 12-latka: krótkie akapity, jedna nowa rzecz, analogia do Scratcha, zero żargonu bez wyjaśnienia.

## Cel

Jedno zdanie: co będzie działać po tej lekcji.

## Co nowego

Jedna koncepcja (5–10 linii + fragment kodu). Jeśli w Scratchu był na to klocek, napisz który.

```cpp
int x = 10;       // pudelko o nazwie x, w srodku liczba 10
x = x + 2;        // wyjmij, dodaj 2, wloz z powrotem
```

## Uruchom

1. Otwórz `gra.cpp` w tym katalogu.
2. Wciśnij **Ctrl+Shift+B** (albo **F6**). Emulator zbuduje się i otworzy okno z grą.
3. Powinieneś zobaczyć: … (co dokładnie widać na ekranie).

## Jak to działa

Kod startowy po fragmentach, każdy z jednym zdaniem wyjaśnienia.

## Zadania

Gwiazdki = trudność. „(test N)" = który wiersz `testy.txt` sprawdza zadanie.

1. ★ …
2. ★ …
3. ★★ … *(test 1)*
4. ★★ …
5. ★★★ …

## Sprawdź sam

Co widać na ekranie po zadaniach albo komenda i oczekiwany wynik:

```
console_sim.exe --game nazwa --frames 120 --trace 30
```

## Dla ciekawych

Coś ponad program, bez podpowiedzi.
